# 붓펜 선택과 장착 계획

최초 작성 / 최종 갱신: **2026-10-07 (KST)**.

**현재 결론: 모나미 일반 붓펜을 후보로 삼아 소프트웨어부터 준비하고,
실제 장착 후 펜 끝 위치와 방향을 측정한다.**

이 문서는 제품 조사와 사용자 장착 계획이다. 보정 보고서나 실제 로봇 설정이
아니며, M1 구현 착수나 M3 실물 보정 완료를 의미하지 않는다.

| --- | --- | --- |

## 공식 자료에서 확인한 규격

사용자가 제공한 판매 화면의 제품은 모나미 일반 붓펜 블랙 계열로 보인다.
세필붓펜·붓펜 드로잉의 치수를 혼용하지 않는다. 사진만으로 세부 생산 버전까지
확정하지 않으며, 실제 제품의 포장·표기를 확인하고 치수를 대조한다.

| 항목 | 조사 결과 | 사용할 때의 한계 |
| --- | --- | --- |
| 전체 길이 | **170.5mm** | 공식 도면의 뚜껑을 닫은 외형, 노출된 붓끝 기준 길이가 아님 |
| 외형 폭 | **12.5mm** | 공식 외형 도면 값, 실제 파지 부위 지름은 별도 측정 |
| 색상 | 블랙 | 사진의 제품 후보 기준 |
| 제품 분류 | 수성마카 / 붓펜 | 제조사 분류 |
| 펜촉 특성 | 사용자의 힘 조절에 따라 다양한 붓 느낌 표현 | 일정한 획 굵기나 접촉력을 보장하는 수치가 아님 |
| 잉크 특성 | 내수성·내광성이 우수하다는 제조사 설명 | A4 용지에서 번짐·배어 나옴은 별도 시험 |
| 리필 | 붓펜 리필잉크로 리필 가능 | 붓펜 드로잉은 별도 제품이며 리필 불가 |

**확인하지 못한 수치:** 무게, 뚜껑을 뺀 전체 길이, 파지 부위의 실제 지름,
붓끝 길이, 접촉력·눌림량별 획 굵기. 임의의 값으로 실물 설정을 채우지 않는다.

파일에 적용한 것은 아니며, 전체 길이의 절반을 장착 오프셋으로 사용하지 않는다.

## X 영상과 우리 작업의 차이

참고: [SO-101 붓 그림 영상](https://x.com/cdngdev/status/2097339677128982873).

| 구분 | 영상에서 확인한 내용 | 확인되지 않은 내용 |
| --- | --- | --- |
| 도구 | 긴 손잡이의 회화용 붓을 로봇 끝에 장착 | 우리 붓펜과 같은 제품·규격 아님 |
| 자세 | 약 10초 장면에서 붓이 종이에 거의 수직으로 내려오는 모습 | 정확한 3D 각도나 전 경로의 수직 유지 여부 |
| 종이 | 가장자리를 파란 테이프로 고정 | 고정력·평면 오차·반복 정밀도 |
| 도구 고정 | 붓이 로봇 끝에 장착된 모습 | 직접 파지만 썼는지, 테이프·별도 홀더를 썼는지 확정 불가 |
| 장착값 | 장면으로 형태를 참고할 수 있음 | 잡는 위치, 펜 끝 변환, 그리퍼 기준 각도·거리 |

영상의 자세는 참고일 뿐 보정값으로 복사하지 않는다. 그림의 성공 장면도
정확한 한글 필기나 반복 성공률의 증거가 아니다.

## 각도와 펜 끝 좌표 구분

**종이에 대한 펜 각도와 그리퍼에 대한 펜 각도는 서로 다른 값이다.**

| 개념 | 의미 | 현재 상태 |
| --- | --- | --- |
| 종이와 펜의 각도 | 펜 축과 종이 평면 사이 각도 | 목표 90도, 실제 달성 가능 범위 미확인 |
| 그리퍼와 펜의 관계 | 그리퍼 로컬 좌표에서 펜의 위치·방향 | 장착 후 측정할 변환, 미설정 |
| 펜 끝 기준점(TCP) | 로봇이 경로를 추종할 때 사용할 붓끝 위치 | 위치·방향 보정 미완료 |
| 종이 평면 | 로봇 좌표에서 종이의 위치·방향 | 실제 장소에서 별도 보정 필요 |

"종이에 수직"이라는 목표만으로 그리퍼 장착 각도를 90도로 지정하지 않는다.
파지 위치가 몸통 중간이라도 붓끝까지 거리는 뚜껑을 닫은 길이의 절반과 다르다.
펜 위치가 도달 가능하더라도 수직 자세까지 만족하는지는 따로 검사한다.

## 다음 개발에 적용할 설계 원칙

아래는 **개발 예정 계약**이며 아직 구현한 기능이 아니다.

1. 글자·종이 경로와 펜 장착 설정을 분리해 기존 한글 경로를 재사용한다.
2. 가상 장착값은 시뮬레이션 전용·미보정으로 표시하고 실물 실행에 사용하지 않는다.
3. 펜 끝 변환, 종이 평면, 접촉 기준, 사용 영역과 보정 버전을 별도로 관리한다.
4. 장착값을 바꾸면 관절 한계·자세·충돌·도달영역·접근/이탈 경로를 다시 검사한다.
5. 실측값이 들어와도 보정·사전검사를 통과하기 전에는 실제 명령을 허용하지 않는다.

기존 `motion_authorized=false`, `physical_calibration_required=true`를 유지한다.
설정 교체가 쉬워지는 것이지, 값만 넣으면 실물 검증 없이 완성된다는 뜻은 아니다.
A4 전체가 로봇의 필기 가능 영역이라고 가정하지 않는다.

## 실물 장착 시 체크리스트

- [ ] 제품 표기와 외형을 확인하고 뚜껑을 뺀 상태의 치수를 기록한다.
- [ ] 파지 부위 지름, 잡는 위치, 그리퍼 기준점에서 붓끝까지의 관계를 측정한다.
- [ ] 측면·정면 사진과 자를 함께 남기고 최종 고정 방식을 기록한다.
- [ ] 몸통을 찌그러뜨리지 않으면서 미끄러짐·회전 없이 유지되는지 확인한다.
- [ ] 테이프 보강 또는 재장착 후 펜 끝·충돌·작업영역을 다시 보정한다.
- [ ] 종이와 받침판을 고정하고 평면·접촉 높이를 새 장소에서 확인한다.
- [ ] M3 사전검사 후 M4 공중 이동 -> 접촉 -> 짧은 선 순서로 진행한다.
- [ ] 일정한 접촉 조건에서 획 굵기·번짐·붙음·종이 손상을 기록한다.

굵은 붓펜에서는 가까운 획과 받침이 붙을 수 있다. 큰 글씨부터 시험하고
최종 글자 크기는 실물 가독성으로 정한다. 현재 호출 화면의 28mm는 미리보기
설정이지 이 펜으로 검증한 최적 글자 크기가 아니다.
