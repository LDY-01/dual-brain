# 실물 SO101 카메라 기둥 충돌 방지

현재 실물 배치는 카메라 기둥이 로봇 오른쪽 회전 영역과 겹친다. 따라서 작업 구역은
기둥 반대편으로 제한하고, 오른쪽 숄더팬 회전은 측정된 절대 각도에서 소프트웨어로
제한한다.

## 원칙

- 팔을 기둥에 닿게 해서 한계를 측정하지 않는다.
- 팔 전체(그리퍼뿐 아니라 팔꿈치와 케이블 포함)가 기둥에서 최소 5 cm 떨어진 지점을
  `measured_clear_boundary_deg`로 기록한다.
- 기록값에서 기본 10도 여유를 더 둔 값을 실제 명령 한계로 쓴다.
- LeRobot의 `max_relative_target=5.0`도 함께 유지한다. 이는 한 번의 급격한 명령을 막는
  장치이며 절대 회전 한계를 대신하지 않는다.
- 로컬 한계 파일이 없거나 값이 비어 있으면 실물 동작을 차단한다.

## 측정 순서

1. 기둥 반대편에 실제 픽·플레이스 작업 구역을 잡고 테이프로 표시한다.
2. 비상시 즉시 12V 전원을 끌 수 있게 준비한다.
3. 현재 포트를 확인한다. 아래 `COM3`는 예시일 뿐이다.
4. 도구가 중앙 자세와 오른쪽으로 조금 움직인 자세를 비교해 값의 증가/감소 방향을
   자동 판정한다. 이때도 팔은 기둥에서 충분히 멀어야 한다.
5. 토크가 해제된 팔을 손으로 천천히 움직여 모든 부위가 기둥과 5 cm 이상 떨어진
   오른쪽 안전 경계에 둔다.
6. 먼저 저장 없이 값을 읽고 검토한다.

```powershell
uv run python -m kwon_lab.tools.capture_shoulder_pan_limit `
  --port COM3 `
  --layout-id <NEW_WORKSPACE_LAYOUT_ID>
```

7. 방향과 수치가 맞으면 같은 명령에 `--save`를 붙인다. 저장 파일은
   `config/real_robot_safety_limits.local.json`이며 Git에 포함되지 않는다.
8. 팔을 안전 구역 중앙에 둔 상태에서 한계 바로 안쪽까지 저속 시험하고, 그 뒤에도
   기둥과 여유가 충분한지 육안으로 확인한다.

실물 배치나 카메라 기둥 위치를 바꾸면 기존 값은 폐기하고 다시 측정해야 한다.
