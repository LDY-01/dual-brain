# 2026-08-19 실물 빨간 블록 물성 반영

## 결론

실측 질량 28.6g과 제공된 STEP의 40×40×60mm 외형, 전 모서리 R1mm 필렛을 MuJoCo에 반영했다. 책상 마찰은 아직 실측하지 않았으므로 단일값으로 확정하지 않고 슬라이딩 마찰계수 0.25–0.80 범위를 시드 고정 무작위화로 평가했다.

같은 시드 5000–5049에서 ACT v2.2를 다시 실행한 결과, 기존 96g 조건과 실물 반영 조건의 전체 성공은 모두 16/50(32%)이었다. 집기 확인은 32/50에서 34/50으로 2건 늘었고 평균 최종 거리는 각각 10.726cm와 10.734cm로 사실상 같았다. 시드별 결과도 기존 조건만 성공 10건, 실물 조건만 성공 10건으로 대칭이었다.

따라서 **질량 변경만을 이유로 한 즉시 재학습은 보류**한다. 다만 절대 성공률 32%는 실물 투입에 충분하지 않으므로, 카메라 보정 후 저속 최초 픽 10회로 sim-to-real 차이를 먼저 측정한다. 실물에서 미끄러짐이나 가벼운 물체의 밀림이 반복되거나 최초 픽이 8/10 미만이면, 28.6g 중심의 질량·마찰 무작위화 데이터로 v2.2를 파인튜닝한다.

## 반영한 값

| 항목 | 반영값 | 확실성 |
|---|---:|---|
| 외형 | 40×40×60mm | STEP 검증 완료 |
| 전체 모서리 | R1mm | STEP의 원형 에지 반지름 검증 완료 |
| 질량 | 28.6g | 실측값 |
| STL 근사 오차 설정 | 0.02mm | 변환 설정값 |
| 재질·표면 | 무광 PLA | 사용자 확인 |
| 작업대 표면 | 흰색 무광 세라믹 | 새 작업공간 기준 사용자 확인 |
| 슬라이딩 마찰 | 0.25–0.80 | 세라믹–PLA 실측 전 불확실성 범위 |
| 내부 질량 분포 | 균일체 근사 | 실제 출력 셸·인필 분포 미확인 |

STEP 형상은 중심을 원점으로 옮긴 뒤 MuJoCo 메시로 변환했다. 메시 충돌은 제공된 볼록 형상을 0.02mm 허용오차로 삼각분할한 근사다. 그리퍼 접촉 마찰과 책상 접촉 마찰이 섞이지 않도록 블록–바닥 접촉 쌍만 별도로 무작위화한다.

## 50회 비교

| 조건 | 전체 성공 | 집기 확인 | 평균 최종 거리 |
|---|---:|---:|---:|
| 기존 각진 박스, 96g, 마찰 1.0 | 16/50 (32%) | 32/50 (64%) | 10.726cm |
| STEP R1 박스, 28.6g, 마찰 0.25–0.80 | 16/50 (32%) | 34/50 (68%) | 10.734cm |

실물 조건의 마찰 구간별 성공은 낮은 구간 5/18, 중간 구간 6/20, 높은 구간 5/12였다. 표본이 작고 시작 자세 영향이 함께 있으므로, 이 수치만으로 실제 세라믹–PLA 마찰값을 역추정하지 않는다.

공개 가능한 기계 판독 요약은 [`benchmarks/results/2026-08-19/red_block_physics_summary.json`](../../benchmarks/results/2026-08-19/red_block_physics_summary.json)에 있다. 원시 시드별 결과는 로컬 `results/physical_block/`에 보관하며 GitHub 업로드 대상에서 제외한다.

## 다음 판정 게이트

1. 손목·상단 카메라 역할을 고정하고 상단 카메라 호모그래피를 실제 테이블에서 보정한다.
2. 숄더팬 기둥 충돌 한계를 실측하고 저속 제한을 활성화한다.
3. 고무 패드 없이 기본 그리퍼로 최초 픽 10회를 저속 수행한다.
4. 8/10 이상이고 체계적 미끄러짐이 없으면 기존 모델과 복구 상태 머신을 계속 사용한다.
5. 8/10 미만이거나 동일 실패가 반복되면 28.6g 중심 질량·마찰 무작위화 데이터로 파인튜닝한다.
