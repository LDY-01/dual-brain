# 2026-08-20 S6 개선 버전 확장 검증

## 목적과 조건

8월 19일 소프트웨어 결함 수정 뒤 성능이 소수 문제 시드에만 맞춰진 결과인지 확인하기 위해 독립 시드를 확대 평가했다. 런타임 제어는 MuJoCo 물체 정답좌표를 사용하지 않고 상단·손목 RGB와 관절 상태만 사용했다. MuJoCo 정답은 에피소드 종료 후 75% 포함 기준 채점에만 사용했다.

- 물체: `real_28g`, 40×40×60mm·28.6g PLA 블록
- 정상 독립 시드: 14000–14049와 14100–14199, 총 150회
- 강제 PLACE 낙하 시드: 15000–15019, 총 20회
- 카메라 성공 여유: 실제 75% 기준에 대해 영상 78%
- 실행 제한: 최대 3작업 주기, 전체 300초

정상 150회의 실제 성공률 95% Wilson 구간은 75.8–87.9%다. 수정 전 50회의 69.2–90.2% 구간과 겹치므로 80%→82.7%의 2.7%p 상승을 일반 성능 향상으로 확정할 수 없다. 첫 독립 50회 84%와 추가 100회 82%는 서로 비슷해 특정 50개 시드에만 맞춰진 정황은 없다.

강제 낙하는 20/20회 주입됐고 11/20(55%)만 최종 복구했다. 수정 전 실제 5/10(50%)보다 5%p 높지만 표본이 작고 95% 구간도 34.2–74.2%로 넓다. 따라서 낙하 복구가 개선됐다고 확정하거나 실물 투입에 충분하다고 볼 수 없다.

## 결론과 다음 개선 순서

이번 수정으로 확정된 개선은 **무제한 장기 실행 제거**다. 정상 성공률은 유지됐지만 유의미하게 상승했다고 증명되지 않았고, 강제 낙하 복구 55%는 목표한 폐루프 픽앤플레이스에 부족하다. S6도 System 2 선택, `return_home`, `emergency_stop`, 실물 실행 어댑터 연결이 남아 있어 완료 상태가 아니다.

다음 소프트웨어 개선은 아래 순서가 타당하다.

1. 재픽 접근 전에 블록과 작업영역 경계의 거리를 확인하고 바깥쪽에서 안쪽으로 미는 접근 방향을 선택해 작업영역 이탈을 줄인다.
2. 300초를 단순 전체 제한으로만 쓰지 않고 탐색·픽·운반·놓기에 단계별 예산을 배분해 성공 가능성이 낮은 반복을 조기에 중단한다.
3. 최종 성공 판정을 마스크 픽셀 비율이 아닌 테이블 평면의 블록·목표 다각형 교차 면적으로 바꾼다.
4. 위 결함을 별도 시드로 검증한 뒤 새 장소 실물 그림자 모드와 저속 최초 픽 10회로 넘어간다.
