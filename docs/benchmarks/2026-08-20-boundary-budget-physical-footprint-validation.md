# 2026-08-20 S6 경계 복구·단계 예산·실물 바닥면 판정 검증

## 결론

새로운 독립 시드에서 정상 픽앤플레이는 **40/50(80%)**, PLACE 중 강제 낙하 후 최종 복구는 **8/10(80%)**였다. 상태 머신 판정과 MuJoCo 사후 정답은 전체 60회에서 모두 일치했다.

성공 판정 오판은 제거했지만 정상 성공률 80%는 정해둔 85% 진입 게이트를 통과하지 못했다. 따라서 이번 검증으로 실물 그림자 모드와 저속 최초 픽 10회를 자동 시작하지는 않았다. 다만 강제 낙하 복구 80%는 기존 11/20(55%)보다 높은 신호이며, 10회 표본이라 일반적 향상으로 확정하지는 않는다.

## 구현한 변경

1. **경계 복구 접근**: 작업영역 경계 4cm 안쪽에서 재집기할 때 프리그래스프를 경계 바깥쪽에 두고 안쪽으로 진입한다. 모서리에서는 두 경계의 안쪽 방향을 합성한다.
2. **단계별 누적 시간 예산**: 관측 5초, 집기 200초, 운반 45초, 놓기 85초를 재시도와 작업 주기 전체에 누적 적용한다. 전체 300초 제한도 동시에 유지한다.
3. **실물 바닥면 투영 판정**: 보이는 빨간 픽셀 자체가 아니라, 카메라가 추정한 중심·회전·자세로 `UPRIGHT` 4×4cm 또는 `TIPPED` 6×4cm 전체 바닥면을 구성한다. 목표 영역 투영 다각형과의 교차 면적이 76% 이상이어야 실제 75% 성공으로 판정한다.
4. **로그와 채점 보완**: 경계 보호 발동, 단계별 남은 예산, 카메라 자세·중심·투영 포함률을 시드별 JSONL에 남긴다. 강제 낙하 복구는 상태 머신과 MuJoCo 사후 정답이 모두 성공해야 성공으로 세도록 수정했다.

## 성공 판정 결함과 수정

첫 구현은 영상에 보이는 빨간 영역의 외곽선을 테이블 평면에 투영했다. 정상 50회에서 거짓 성공 2회·거짓 실패 1회, 강제 낙하 10회에서 거짓 성공 1회가 나왔다. 블록 대부분이 목표 밖에 있어도 아주 작게 보이는 빨간 부분만 목표 안에 있으면 100%로 계산되는 것이 원인이었다.

이 방식을 폐기하고 실물 바닥면 투영으로 바꾼 뒤, 기존 거짓 성공 시드 16028·16037은 첫 잘못된 놓기를 거부하고 재복구해 실제 포함률 99.97%로 성공했다. 강제 낙하 시드 17004는 작업영역 밖 실패로 올바르게 거부했다. 수정에 사용하지 않은 최종 독립 60회에서는 판정 불일치가 0회였다.

## 기존 결과와의 비교

- 정상 실제 성공률은 기존 독립 150회의 124/150(82.7%)에서 이번 40/50(80%)로 2.7%p 낮아졌다. 신뢰구간이 넓게 겹치므로 성능 하락이나 향상 모두 확정할 수 없다.
- 강제 낙하 복구는 기존 11/20(55%)에서 8/10(80%)로 25%p 높았다. 다만 이번 95% 구간이 49.0–94.3%로 넓고 기존 구간과 겹치므로 일반적 향상으로 확정하지 않는다.
- 판정 불일치는 기존 정상 3/150에서 이번 정상 0/50로 줄었고, 수정 중 발견한 거짓 판정 4건도 표적 회귀에서 재현되지 않았다. 이 부분이 이번 수정에서 가장 명확한 개선이다.

## 판정과 다음 작업

정상 80%는 85% 진입 기준을 넘지 못했다. 즉 이번 4가지 작업 중 경계 접근·단계 예산·실물 바닥면 판정·독립 회귀시험은 모두 완료했지만, 조건부인 실물 그림자 모드와 저속 최초 픽 10회는 자동 진행하지 않았다.

다음 순서는 다음과 같다.

1. 새 장소에서 로봇·기둥·작업영역과 손목·상단 카메라를 고정하고, PnP 역할·호모그래피·숌더팬 안전 한계를 다시 검증한다.
2. 모터를 보내지 않는 그림자 모드에서 실물 블록 자세·바닥면 포함률·낙하 판정과 ACT 제안 관절값을 검증한다.
3. 안전 프리플라이트가 통과하면 저속 최초 픽 10회를 수행해 실제 집기 병목을 분류한다. 0–7회 성공이면 집기 파인튜닝을 우선하고, 8회면 10회를 추가하며, 9–10회면 전체 픽앤플레이스로 넘어간다.
