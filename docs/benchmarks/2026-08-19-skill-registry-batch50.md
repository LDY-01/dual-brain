# 2026-08-19 S6 카메라 기반 픽앤플레이스 기준선과 개선 검증

## 목적

MuJoCo 물체 정답좌표를 런타임 제어에 사용하지 않고 상단·손목 RGB와 로봇 관절 상태만으로 `관측 → 집기 → 운반 → 6cm 놓기 → 실패 복구`를 실행했다. MuJoCo 정답은 에피소드 종료 후 75% 포함 기준 채점에만 사용했다. 실물 반영 `real_28g` 블록 조건에서 정상 새 시드 50회와 PLACE 접근 중 강제 낙하 10회를 평가했다.

## 수정 전 기준선

| 평가 | 상태 머신 판정 | MuJoCo 정답 | 판정 불일치 |
|---|---:|---:|---:|
| 정상 시드 12000–12049 | 41/50 (82%) | 40/50 (80%) | 1회 |
| 강제 낙하 시드 13000–13009 | 4/10 (40%) | 5/10 (50%) | 1회 |

정상 평가의 거짓 성공은 시드 12044 한 건이다. 카메라는 성공으로 판정했지만 실제 포함률은 74.953%로 75% 기준보다 0.047%p 낮았다. 강제 낙하의 거짓 실패는 시드 13001 한 건으로, 상태 머신은 접근 중 낙하 실패로 종료했지만 최종 실제 포함률은 100%였다.

정상 평가 평균 시간은 119.85초, 중앙값은 91.57초, p95는 211.69초였다. 최장 회차는 626.59초였으며 120초로 선언한 스킬 제한을 실제 실행 중 끊지 못하고 사후에만 실패 처리한 사례가 2회 있었다.

강제 낙하는 10/10회 실제 주입됐다. 최상위 실패 표시는 모두 `drop_during_place_approach`였지만 복구 내부를 펼치면 놓기 확인 실패 4회, 운반 재낙하 1회, 시간 초과 뒤 다시 PLACE 접근 낙하 1회였다. 따라서 감지 자체보다 복구 뒤 파지·재운반·재놓기와 최종 판정이 병목이다.

## 수정 대상으로 확정한 결함

1. 120초 제한이 실행을 중단하지 않고 반환 후에만 위반을 판정한다.
2. 카메라 75% 경계에 안전 여유가 없어 실제 74.953%를 성공으로 오판했다.
3. PLACE 실패 뒤 한 번의 선언형 복구만 시도하고, 그 복구 PLACE가 실패하면 전체 상태 머신이 종료된다.
4. 접근 중 떨어진 블록이 이미 목표에 안정적으로 들어가도 다시 성공을 확인하지 않는다.
5. `coarse_position_unreachable`을 즉시 비재시도 실패로 처리해 다른 관측·조준 기회를 사용하지 않는다.
6. 배치 요약이 최상위 실패만 표시해 내부 복구의 실제 마지막 실패를 가린다.

기계 판독 기준선은 [`skill_registry_batch50_drop10_baseline.json`](../../benchmarks/results/2026-08-19/skill_registry_batch50_drop10_baseline.json)에 저장한다. 시드별 원시 JSONL과 실행 중간 요약은 로컬 `outputs/skill_registry_batch_2026-08-19/`에 보관한다.

## 반영한 소프트웨어 개선

1. 각 제어 스텝과 IK 반복에서 스킬 기한을 검사하고 전체 작업을 최대 3주기·300초로 제한했다.
2. 실패한 픽·운반·놓기를 한 번의 복구로 끝내지 않고, 다음 작업 주기에서 영상 재탐색부터 다시 시작한다.
3. 쓰러진 블록의 복구 파지는 그리퍼를 다시 조이고 접촉 안정화를 기다린다.
4. 복구 운반은 느리게, 복구 놓기는 더 작은 정렬 스텝과 긴 이동시간으로 실행한다.
5. PLACE 접근 중 떨어졌더라도 블록이 목표에 들어갔으면 그리퍼를 비우고 상단 영상으로 최종 성공을 확인한다.
6. `coarse_position_unreachable`은 즉시 종료하지 않고 다른 관측·조준 기회를 사용한다.
7. 실제 75% 기준의 경계 오판을 줄이기 위해 카메라 성공 기준에 78% 안전 여유를 둔다.
8. 배치 결과에 전체 작업 주기, 내부 복구 실패, 거짓 성공·거짓 실패를 별도로 기록한다.

공통 스킬 계약 검사는 기존 5종과 실행 중 시간제한 중단을 합쳐 6/6을 통과했다.

## 문제 시드 회귀시험

기존 정상 문제 시드 10개 중 5개가 수정 후 성공했다. 남은 실패는 작업영역 밖 3회와 전체 300초 제한 2회였다. 기존 74.953% 거짓 성공 시드 12044는 수정 후 실제 성공으로 완료했다. 기존 강제 낙하 문제 시드 6개를 새 프로세스에서 검증한 결과 5/6(83.3%)을 복구했고 카메라·정답 불일치는 없었다. 실패 1회는 300초 전체 제한에 도달했다.

문제 시드 회귀는 결함 재현용으로 선별한 표본이므로 일반 성공률로 해석하지 않는다.

## 수정 후 독립 정상 시드 50회

수정 과정에서 사용하지 않은 시드 14000–14049로 다시 평가했다.

| 지표 | 수정 전 기준선 | 수정 후 독립 50회 |
|---|---:|---:|
| 상태 머신 성공 | 41/50 (82%) | 42/50 (84%) |
| MuJoCo 사후 정답 성공 | 40/50 (80%) | 42/50 (84%) |
| 평균 집기 시도 | 2.34회 | 1.98회 |
| 최대 집기 시도 | 9회 | 7회 |
| 최장 실행시간 | 626.59초 | 300.61초 |
| 카메라·정답 불일치 | 1회 | 2회 |

수정 후 실패 8회는 작업영역 밖 4회와 전체 300초 제한 4회였다. 판정 불일치는 실제 포함률 80.516%를 실패로 본 시드 14037과 실제 포함률 74.711%를 성공으로 본 시드 14040이다.

실제 성공률은 80%에서 84%로 4%p 상승했지만 두 95% 구간이 겹치므로 일반 성능 향상이 통계적으로 확정됐다고 보지 않는다. 명확히 확인된 개선은 무제한 장기 실행 제거, 평균 집기 시도 감소와 선별된 강제 낙하 문제의 복구율 상승이다. 다음 병목은 블록을 작업영역 밖으로 미는 행동, 어려운 회차의 300초 소진과 75% 경계 판정이다.
