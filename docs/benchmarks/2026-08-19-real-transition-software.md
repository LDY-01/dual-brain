## 구현 결과

최종 연결 상태에서 노트북 내장 카메라와 Innomaker U20CAM 두 대가 확인됐다. 화면과 한 대씩 분리 연결한 PnP 비교를 통해 index 1을 손목, index 2를 상단으로 로컬 등록했고 두 카메라가 모두 1280×720 프레임을 반환해 카메라 게이트를 통과했다. 새 장소 로컬 workspace 파일은 안전 확인을 모두 `false`로 두었고 안전 한계와 보정도 없으므로 전체 프리플라이트는 `motion_authorized=false`로 차단됐다.

부분 가림에서 자세 근거가 부족한 프레임은 낮은 신뢰도 또는 `UNKNOWN`으로 처리해 반대편 시야로 전환한다. 시드 1908에서는 이를 반영한 행동 가능한 자세 오판이 0건이었다.

위 표는 현재 코드에서 시드 1908을 다시 실행한 재현 결과이며 전체 게이트를 통과했다. 추가 시드 20260819의 200조건에서는 정상과 부분 가림 게이트는 통과했지만, 조명 변화 XY 오차 p95가 15.65mm로 기준 15mm를 0.65mm 초과해 전체 판정은 실패했다. 부분 가림의 행동 가능한 자세 오판도 3/50이므로, 이 벤치마크는 기능 가능성을 보여줄 뿐 새 장소 실물 강건성을 보장하지 않는다. 수직 설치와 실제 조명에서 다시 측정하고 임계값을 튜닝해야 한다.

카메라를 XY 최대 2.5cm, 높이 최대 4cm, 기울기 최대 3도 정도 바꾸고 옛 호모그래피를 사용하면 위치 오차 p95가 44.05mm로 증가했다. 따라서 장소 이전 후에는 카메라가 비슷해 보이더라도 호모그래피를 다시 만들어야 한다.

실제 상단 카메라 프레임에서는 화면 가장자리의 빨간 포장지가 블록과 같은 색 마스크에 합쳐졌다. 모든 빨간 픽셀을 하나로 취급하지 않고 연결요소를 나눠 비테두리 독립 물체를 우선하도록 개선한 뒤 블록만 분리했으며, 시뮬레이션 회귀 40조건이 통과했다. 새 장소 작업영역에서도 빨간 잡동사니는 제거하는 것이 원칙이다.
